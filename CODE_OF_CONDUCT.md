# Code of conduct

Firedrill follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work, and don't harass anyone. This applies in issues, pull requests, discussions and anywhere else you act on behalf of the project.

To report a problem, contact the maintainer, [@sk1122](https://github.com/sk1122), through GitHub. Reports are kept confidential.
